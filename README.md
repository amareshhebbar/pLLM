# PocketLLM

Private, offline AI chat. Runs entirely on-device — no internet required after setup.

## Download

**Option 1 — Google Play (recommended)**

[Download on Google Play](PLAY_STORE_LINK_HERE)

**Option 2 — Direct APK (if the Play link doesn't work / not yet approved)**

[Download APK from Google Drive](DRIVE_LINK_HERE)

To install from the Drive link:
1. Download the `.apk` file to your Android device.
2. Open it. If prompted, allow installs from this source (Settings → Security → Install unknown apps).
3. Tap Install.

## Requirements

- Android 8.0 (API 26) or higher
- ~3–6 GB free storage per downloaded model

## What it does

- Download and run open-source LLMs (Qwen, Llama, SmolLM, Phi) fully offline
- Smart router auto-picks the best downloaded model per message
- Persona system, memory, and MCP tool calling
- No data leaves your device
